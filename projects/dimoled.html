DimOLED: Hardware-Level Burn-In Protection Utility

A zero-overhead Windows background daemon that protects OLED and mini-LED displays from static image degradation. Regulates physical panel luminance directly through WMI and DDC/CI hardware registers without rendering fake translucent desktop overlays.

View Source on GitHub
Operating System Windows 10 / 11 (x64 & ARM64)
Hardware Protocol WMI Monitor · DDC/CI I2C Bus
Input Hooking Win32 `GetLastInputInfo` (Zero Poll)
CPU Footprint 0.00% during normal idle sleep

1. Why Software Dimming Fails OLED Displays

Common third-party screen dimming utilities create a transparent black fullscreen window with the WS_EX_LAYERED and WS_EX_TRANSPARENT flags. While this makes the screen look darker, it is a catastrophic illusion for OLED hardware:

  • No Voltage Reduction: The display panel's internal power supply and LED driver circuits continue operating at full operating voltage and nominal diode temperatures.
  • GPU Overhead: Forces the Desktop Window Manager (DWM) to blend the translucent surface every refresh cycle (120Hz-240Hz), burning unnecessary laptop battery.
  • Fullscreen Conflicts: Causes window focus stealing and HDR tone-mapping corruption in professional color grading software and 3D games.

2. The WMI / DDC/CI Hardware Approach

DimOLED communicates directly with the physical display controller. When user inactivity exceeds the configured threshold, it dispatches calls to the underlying hardware driver: 

# Native WMI Physical Brightness Call in PowerShell
$wmi = Get-WmiObject -Namespace root/wmi -Class WmiMonitorBrightnessMethods
if ($wmi) {
    # Set brightness physically: Timeout = 0s, TargetBrightness = 10%
    $wmi.WmiSetBrightness(0, 10)
}

# Monitoring user activity via Win32 GetLastInputInfo
Add-Type @'
using System;
using System.Runtime.InteropServices;
public class UserInput {
    [DllImport("user32.dll")]
    public static extern bool GetLastInputInfo(ref LASTINPUTINFO plii);
    public struct LASTINPUTINFO {
        public uint cbSize;
        public uint dwTime;
    }
}
'@

3. Key Capabilities

Genuine Panel Power Reduction

Directly throttles diode current, significantly reducing thermal buildup in organic emissive layers and halting sub-pixel aging on taskbars and static IDE windows.

Zero-Latency Recovery

The instant any mouse movement or keystroke registers, hardware brightness snaps back to the user's working level without UI flicker or window transitions.

Multi-Monitor DDC/CI Support

Compatible with external OLED monitors connected via DisplayPort or HDMI supporting VESA Display Data Channel Command Interface (DDC/CI).

Silent Background Execution

Runs as a lightweight background daemon without taskbar icons or intrusive prompts, consuming virtually zero system resources.

ابزار محافظت از نمایشگر DimOLED: کنترل روشنایی در سطح سخت‌افزار

یک ابزار سبک پس‌زمینه برای سیستم‌عامل ویندوز که از ماندگاری تصویر و سوختگی پیکسل‌های نمایشگرهای OLED و Mini-LED جلوگیری می‌کند. تنظیم فیزیکی جریان دیودهای پنل از طریق رابط‌های WMI و پروتکل DDC/CI بدون استفاده از لایه‌های شفاف کاذب نرم‌افزاری.

۱. چرا نرم‌افزارهای سنتی تاریک‌کننده برای پنل‌های OLED مخربند؟

اغلب برنامه‌های تاریک‌کننده صفحه در اینترنت، یک پنجره سیاه نیمه‌شفاف را روی کل دسکتاپ می‌کشند. این کار در پنل‌های OLED نه تنها مفید نیست بلکه آسیب‌زننده است:

  • عدم کاهش ولتاژ و حرارت: مدار درایور مانیتور همچنان با حداکثر توان کار می‌کند و پیکسل‌ها زیر بار حرارتی باقی می‌مانند.
  • اتلاف انرژی در کارت گرافیک: موتور کامپوزیت ویندوز (DWM) در نرخ‌های ۱۲۰ تا ۲۴۰ هرتز مجبور به ترکیب دو لایه گرافیکی است که مصرف باتری لپ‌تاپ را افزایش می‌دهد.
  • اختلال در بازی‌ها و نرم‌افزارهای گرافیکی: لایه‌های شفاف نرم‌افزاری موجب تداخل با حالت تمام‌صفحه و پروفایل‌های رنگی HDR می‌شوند.

۲. راه‌حل مهندسی DimOLED: تغییر مستقیم رجیسترهای سخت‌افزار

نرم‌افزار DimOLED مستقیماً با درایور کنترلر سخت‌افزاری نمایشگر ارتباط برقرار می‌کند. با گذشت مدت زمان عدم فعالیت کاربر، مقدار روشنایی از طریق WMI کاهش می‌یابد: 

# فراخوانی متد سخت‌افزاری تنظیم روشنایی مانیتور
$wmi = Get-WmiObject -Namespace root/wmi -Class WmiMonitorBrightnessMethods
if ($wmi) {
    # اعمال مقدار فیزیکی: زمان انتقال صفر ثانیه، روشنایی ۱۰ درصد
    $wmi.WmiSetBrightness(0, 10)
}
